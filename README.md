## Fitur

- Beranda berisi ringkasan dan daftar alat
- Koleksi dengan pencarian judul dan filter kategori
- Detail alat dengan tombol hapus
- Form tambah alat, tersimpan di localStorage
- Statistik jumlah alat per kategori
- Halaman Tentang dan 404

## Menjalankan secara lokal

cd app
npm install
npm run dev

## Konsep React yang dipakai

- Komponen dan props
- useState dan useEffect
- Context API
- Custom hook (useKoleksi, useLocalStorage)
- React Router
- fetch dengan async/await
